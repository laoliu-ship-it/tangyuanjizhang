# 正文

很多独立开发者、小团队最头疼的不是写代码，而是"官网首图 / 产品广告图丑成什么样"。招不起设计师，自己用 PS 又调不出高级感，网上随便找的模板一眼假。

这篇文章把我给"汤圆记账"（一款餐饮多店记账产品）做广告 Banner 的完整过程写出来，包括用的工具、踩的坑，以及几个可以直接照搬的技巧。

## 一、用的什么工具：Claude Code 的 brandkit 技能

用的是 **Claude Code**（Anthropic 官方 CLI 编程助手）里的一个技能包（Skill），叫 **brandkit**，专门用来生成品牌视觉物料——logo、banner、品牌手册这一类。

它不是"随便画一张好看的图"，而是内置了一整套品牌设计方法论：

- 先想清楚品类、受众、品牌性格、核心隐喻，再决定视觉方向
- 强制"少即是多"：文字要少，留白要大
- 有明确的排版语言：统一的网格、间距、圆角，强调色只用一种反复呼应
- 反对"通用 AI 风"：渐变紫蓝光晕、意义不明的火花图标、瞎拼凑的动物 logo，一律不要

换句话说，这个技能更像是"请了一个有审美原则的设计总监"，而不是抽卡式地"生成一张随机好看的图"。

## 二、实操技巧（重点）

### 技巧 1：先挖真实信息，不要拿"临时名字"直接设计

项目文件夹叫"饭店记账"，但我没有直接拿这个当品牌名去做设计，而是先翻了项目代码里的 `index.html`、登录页文案，发现产品对外的真实名字其实是**"汤圆记账"**。

"汤圆"是圆的、软糯的、团圆的意象，天然适合做"圆满记账"的隐喻——比"饭店记账"这种大白话名字有戏得多。

**技巧**：动手设计之前，先去代码 / 文案里找"真实品牌资产"，而不是拿目录名、需求文档里的临时命名直接上。

### 技巧 2：把核心功能"翻译"成一个画面，而不是堆图标

这款产品的核心功能有 OCR 拍照识别、AI 自动分类、多店管理、数据统计四个。如果四个都用图标平铺，会显得很像"信息图"，没有故事感。

我的做法是：挑一条功能主线——拍照小票 → 扫描线 → 自动生成账目卡片——做成一个可视化的"转化过程"，其余功能收进底部的功能标签里做点缀。

**技巧**：一张 banner 只讲一个故事，其余信息降级为辅助说明，不要平均用力。

### 技巧 3：logo 用"负空间"做双关，比找图库图标高级

Banner 上的 logo 是一个金色圆环，中间挖空出一个对勾——远看像"汤圆"（圆形团子），细看是"已核账的对勾"。这是 brandkit 技能里提到的**负空间（Negative Space）设计法**：用留白 / 挖空表达第二层含义，而不是简单堆叠两个图形。

### 技巧 4：没有图像生成接口，也能出图——用代码画图 + 截图

这是最意外的收获。我用的这套环境其实**没有接入 Midjourney / DALL-E 这类图像生成接口**，理论上没法直接"画"一张图。

解决方法：让 AI 把 banner 写成一个 HTML + CSS + SVG 页面（相当于用代码画图），再用 headless Chrome 把这个页面截图导出成 PNG。

好处很明显：

- 文字永远清晰不糊（AI 画图最容易在中文文字上出错、出现乱码）
- 改文案、改颜色只需要改代码，秒级重新出图，不用像抽卡工具那样"再抽一次求好运"
- 100% 可控：logo 位置、圆角大小、颜色数值都是精确数字，不靠运气

如果你的团队里有前端，这个方法比任何 AI 画图工具都稳，尤其适合需要反复微调文字的营销物料。

### 技巧 5：出图之后自己"找茬"一遍

第一版截图里，左上角其实多渲染出了一个没用上的 CSS 规则造成的杂色方块——这是常见的"写代码时留了一段没删干净的样式"，不细看容易漏掉。

**技巧**：图出来之后，把它当成一次小型的设计走查（design QA），逐个角落看一遍，而不是扫一眼大概齐就收工。

## 四、写在最后

这套流程本质上不是"AI 帮你设计"，而是"一套明确的设计方法论 + 你项目里的真实信息 + 代码可控的渲染方式"三者结合。用的工具是 Claude Code 的 **brandkit 技能**，但真正好用的地方不是"点一下就出图"，而是它逼着你先想清楚品牌到底想说什么。

如果你也是没有设计师的小团队，这套方法可以直接照搬：

**先挖真实品牌资产 → 只讲一个功能故事 → 用负空间做 logo 双关 → 没有图像接口就用代码画图截图 → 出图后自己走查一遍。**
